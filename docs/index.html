AI auth

Choose one

Create one at console.anthropic.com. Pay-per-use — a few cents a month — and works for anyone with an Anthropic account. Recommended default.

◆ Run claude setup-token in your terminal, approve in the browser it opens, then paste the token it prints below. Uses your Claude Pro/Max subscription instead of API billing — no per-run cost — and the token lasts about a year.
◆ Your keys are encrypted in this browser — sealed with libsodium against your repository's own public key — and sent straight to GitHub, where they become repository secrets only your workflow can read. Nothing is sent anywhere else. This page has no server and no analytics; you can read every line of it with View Source.

Email delivery

From resend.com/api-keys (free tier covers personal volume).

◆ The from-address must be on a domain you've verified in Resend at resend.com/domains — an unverified domain is the single most common reason the first digest never arrives, and returns a 403 that looks like a bad API key but isn't.
◆ These addresses are stored as encrypted EMAIL_TO / EMAIL_FROM secrets, the same way as your API keys — never written into the committed config.yaml, which stays readable by anyone if your fork is public.

Gmail accounts

Each account needs its own 16-character app password, not your normal Google password. Enable 2-Step Verification at myaccount.google.com/security, then create one per account at myaccount.google.com/apppasswords.

Rhythm

A ceiling, not a quota. If the window was quiet, a two-item digest is the correct answer.

mailtriage ships two runs a day, 12 hours apart. Mail older than this is ignored — and there's no other dedupe, so it must cover the gap between runs or mail arriving inside it is skipped forever.
