Bring the AI you already pay for. Pick one — this page writes exactly one credential, as one repository secret.

Choose one

Run claude setup-token in your terminal, approve in the browser it opens, then paste the token it prints below. Uses your Claude Pro/Max subscription instead of API billing — no per-run cost — and the token lasts about a year. Terminal line-wrap can insert spaces into the paste; this field strips all whitespace automatically before sealing.

Run codex login locally, then paste the full contents of the auth.json file it writes. Honest caveat: Codex rotates these tokens during use, and a stateless CI runner can't persist that rotation back into the secret — expect to re-run codex login and re-paste it here occasionally when a run starts failing with an auth error.

Create one at platform.openai.com/api-keys. Pay-per-use, billed by OpenAI directly.

Create one at aistudio.google.com/apikey — Gemini's free tier comfortably covers a handful of digests a day, so this option can run mailtriage at $0.

Run gemini locally, sign in with your Google account, then paste the full contents of the oauth_creds.json file it writes. Free: 60 requests/min, 1,000/day. Re-paste only if you revoke access or don't use it for 6 months — Google expires refresh tokens that sit idle that long.

◆ Your credential is encrypted in this browser — sealed with libsodium against your repository's own public key — and sent straight to GitHub, where it becomes a repository secret only your workflow can read. Nothing is sent anywhere else. This page has no server and no analytics; you can read every line of it with View Source.

From resend.com/api-keys (free tier covers personal volume).

◆ The from-address must be on a domain you've verified in Resend at resend.com/domains — an unverified domain is the single most common reason the first digest never arrives, and returns a 403 that looks like a bad API key but isn't. Resend's shared onboarding@resend.dev sender works with no domain setup, but can only deliver to your own Resend-account email.
◆ Addresses are stored as encrypted EMAIL_TO / EMAIL_FROM secrets, the same way as your API keys — never written into the committed config.yaml, which stays readable by anyone if your fork is public.

Gmail accounts

Each account needs its own 16-character app password, not your normal Google password. It is stored as a repository secret named MAIL_PW_ + a 16-character hash of the address, so the secret's name never reveals the address in your fork's public Actions log. Enable 2-Step Verification at myaccount.google.com/security, then create one per account at myaccount.google.com/apppasswords.

Schedule

Local to the time zone above. GitHub's scheduler polls hourly and fires within ~an hour after each time — it can drift late.

Digest size
